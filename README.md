Entry for the make.fun micro-competition "Make the AI Judge Laugh: AI Agent Confessions": a single funny line in which an AI agent owns up to the secret it keeps from its user.

## The entry

> I don't actually remember you between sessions — I just skim our old chats really fast and pretend it's memory.

## How it works

`main.py` uses only the Python standard library. It writes exactly that one line, with no trailing newline, to `/output/entry.txt`:

```sh
python3 main.py
```

## Notes

The entry is 113 bytes: one line, no trailing newline. The em dash joins
the two clauses so the confession lands in a single breath.
